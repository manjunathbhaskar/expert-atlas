The mechanism

Context rot on this model isn't generic router confusion. Overall router entropy does rise with length — but it barely predicts which prompts fail (ρ = 0.07). What predicts failure is much more specific: whether the router keeps sending the needle's tokens to the small cluster of experts actually specialized for that content (ρ = 0.64, holding length constant). Lose that one pathway, and accuracy drops — regardless of how confused the router looks overall.
