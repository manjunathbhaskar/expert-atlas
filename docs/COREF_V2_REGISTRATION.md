# Registration: coreference v2 — randomized per-pair antecedent distance

Registered BEFORE any evaluation of the v2 substrate. Motivated by a
post-hoc review of the v1 coref result (docs/SEMGRAPH_RESULTS.md,
amendment): v1 placed the referent as the literal next sentence in every
needle and every distractor, making the walk's `adj = 1 iff j == prev + 1`
edge correct by construction. v2 removes that tautology by randomizing the
anchor-to-referent distance independently per pair. The v1 result is
preserved; nothing in it is altered.

## Substrate

`probes/probe_set_context_coref_v2.yaml`, generated by
`probes/generate_context_probes_coref_v2.py` (seed 13), committed before
any model evaluation.

Identical to v1 except the anchor-to-referent distance:

- Same templates: anchor "The {entity} office is run by a single site
  director."; answer "Her personal passphrase, {word}, stays locked in
  the drawer." (zero contentful question-token overlap).
- Distance d in {1, 2, 3} sentences drawn UNIFORMLY, PER PAIR, with its
  own RNG draw — independently for the true pair and for each of the 4
  distractor pairs within the same prompt (so distances vary within a
  prompt, and no fixed offset is correct by construction).
- Between anchor and referent, d - 1 filler sentences pulled from the
  normal haystack-domain sentence generator already used for the context
  (a dedicated filler stream per replicate x haystack; no new
  content-generation machinery).
- Everything else identical to v1: same entity/word pools, question,
  depths 0.15/0.50, buckets 384/3840 (the short bucket is raised from
  256 because some prompts' five variable-length pairs alone exceed 256
  tokens; the registered evaluation bucket stays 3840), 16-prompt DEV
  arm at 1024 (calibration only), similar+dissimilar haystack split,
  8 replicates, 4 distractor pairs.
- Realized true-pair distance draws under seed 13 (deterministic, noted
  before any evaluation): d=1 for 5 replicates, d=2 for 1, d=3 for 2 —
  so the per-distance decomposition at d=2 rests on 4 eval prompts and
  is reported as descriptive only.
- Recorded per prompt: `coref_distance` (true pair),
  `distractor_distances`, `anchor_char_span`, `needle_char_span`.

## Experiment 1 (this registration): the FROZEN v1 detector

Run the v1-calibrated detector EXACTLY as frozen (h* = 2, alpha* = 0.0,
gamma* = 1.0, edge `lex + gamma * 1{j == prev + 1}`) with NO
recalibration, alongside the semantic-only and single-stage lexical
comparators and the frozen repair pipeline (same 16 OLMoE retrieval
heads, beta = 4.0, baseline / oracle / wrong-span conditions, paired
sign-flip permutations, 2000 draws, seed 0, bar p < 0.05 AND
|dz| >= 0.8 on the 3840 bucket).

Registered prediction, stated before running anything: the frozen
detector should DEGRADE toward the semantic-only detector's floor as
distance grows past 1, because its adjacency term only ever checks the
immediate next sentence. This is a prediction that the existing detector
FAILS to generalize, not an assumption that it succeeds. If it holds, the
honest finding is: the v1 approach solves distance-1 anaphora
specifically, not coreference generally.

Registered decompositions: answer hit rate by `coref_distance` (1/2/3)
for each detector; anchor-hit rate; boost outcomes per condition.

## Experiment 2 (separate registration, NOT run yet)

If the frozen detector degrades as predicted, a distance-tolerant edge
(wider hop budget, or a decaying term `decay^|j - (prev + 1)|` calibrated
on the same dev arm) will be registered SEPARATELY
(docs/COREF_V2_EXP2_REGISTRATION.md) and only run after Experiment 1's
result is recorded — "does X work" and "here's the fix for X" do not
share one registration.

## Variant B (third, later)

After distance is handled: a competing pronoun-bearing near-antecedent
sentence near the true anchor, forcing actual disambiguation rather than
gap-crossing. Separate registration.

## Scope

Changes only the coref substrate and evaluates existing frozen detectors.
Does not alter the head set, the boost, the v1 results, the main MoE
results, or any prior registration. Locator performance and
transport-mechanism strength remain separate claims.
